# AI Engineering Learning Journey

## About This Repository

This repository documents my journey toward becoming an **AI Engineer** while pursuing a Computer Science degree.

My goal is to build a strong foundation in Python, mathematics, data science, and machine learning before progressing to more advanced AI concepts and practical applications.

Rather than focusing only on theory, I'm learning by implementing algorithms, solving exercises, analyzing data, and building small projects along the way.

This repository serves as a record of my progress, experiments, and practical understanding of AI and machine learning.

- Implementing machine learning algorithms from scratch
